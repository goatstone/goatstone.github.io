About Goatstone

Goatstone is Jose Collas, a web developer working mainly in JavaScript, TypeScript, CSS and HTML. I build interactive, data-driven web applications: visualizations, maps and tools that make data easier to explore.

This site collects some of that work. Start with the Work page, or get in touch about a project.

What I work with

  • Front end: JavaScript, TypeScript, React, CSS, HTML, SVG
  • Visualization: D3.js, Matter.js (2D physics), maps and geospatial data
  • Reactive patterns: RxJS and React hooks
  • Back end and devices: Node.js, MQTT, Android sensors, IoT experiments
  • Distributed ledgers: Hedera, with the Hashgraph Developer Course completed in 2026 (see Certifications)
